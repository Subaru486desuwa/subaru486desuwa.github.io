## Editing the website / 更新主页

This is a small static website. No build tools, package installation, external fonts, or JavaScript are required.

| File | Purpose |
| --- | --- |
| `index.html` | Name, affiliation, biography, interests, project descriptions, and contact links / 个人信息与正文 |
| `styles.css` | Layout, colors, mobile styles, and print styles / 样式 |
| `favicon.svg` | Browser icon / 网站图标 |
| `robots.txt` and `sitemap.xml` | Search engine discovery / 搜索引擎索引 |
| `.nojekyll` | Publish the files as a plain static site |

To update your information, edit `index.html` and commit the change to `main`. Keep the visible name, contact email, page title, and metadata consistent. Project titles link directly to their public repositories.

更新时直接修改 `index.html`，提交到 `main` 后 GitHub Pages 会自动重新发布。姓名、邮箱、页面标题和 metadata 应保持一致。

## GitHub Pages

Use **Settings → Pages → Build and deployment → Deploy from a branch**, with branch **`main`** and folder **`/ (root)`**.
